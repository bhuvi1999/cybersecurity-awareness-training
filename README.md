# Cybersecurity Frameworks and Awareness Training for Resilient Hearts
## Project Overview

This repository contains deliverables for a team-based Cybersecurity Capstone Project (ISEC3999) completed at Bow Valley College for Resilient Hearts, a healthcare organization. The project focused on designing and implementing cybersecurity frameworks and awareness training programs to protect sensitive personal and health information, ensuring compliance with regulations such as HIA, FOIP, and HIPAA. Leveraging Microsoft 365 tools (Outlook, Teams, SharePoint, OneDrive), our team developed robust security policies, training modules, and interactive exercises to mitigate cyber threats and foster a security-conscious culture.

### Team Members: Bhuvaneshwari Rajendran, Megha Issack, Femiwa Adepegba, Muaz Muzaffer, Richard Takang, Sedat Cavdar

## Project Scope
- Developed training modules on phishing prevention, password security, multi-factor authentication (MFA), secure remote work, and BYOD practices.
- Created policies for data loss prevention (DLP), email tenant hardening, secure file sharing, and physical/electronic access controls.
- Designed interactive exercises, including phishing simulations, ransomware response drills, and secure document-sharing challenges.
- Implemented data protection strategies such as encryption, anonymization, role-based access control (RBAC), and regular security audits.
- Ensured compliance with privacy laws through data minimization, consent-based data sharing, and incident response protocols.

## My Contributions
#### As a key contributor to this team project, I focused on the following areas:
- #### Incident Response, Malware, and Culture:
    - Led the development of training modules to recognize and respond to cybersecurity incidents, including phishing, ransomware, and malware attacks.
    - Designed practical exercises, such as ransomware attack simulations and incident response drills, to enhance employee preparedness.
    - Promoted a proactive cybersecurity culture through awareness campaigns and streamlined incident reporting protocols.
- #### Physical & Electronic Security and Data Loss Prevention:
    - Contributed to guidelines for securing physical IT resources (e.g., server rooms, workstations) and electronic access controls (e.g., MFA, RBAC).
    - Developed DLP policies for email and file sharing to prevent unauthorized data leaks, utilizing Microsoft 365’s security features.
- #### Multi-Factor Authentication (MFA):
    - Created training content explaining the importance of MFA in protecting sensitive information and its role in healthcare security.
    - Provided step-by-step guides for setting up and using MFA on Resilient Hearts’ systems, such as Microsoft 365 and EHR platforms.
    - Highlighted real-world examples of MFA preventing unauthorized access in healthcare breaches.
- #### Email Tenant Hardening and Secure Attachments:
    - Developed strategies for email tenant hardening, including disabling legacy protocols (IMAP/POP) and implementing mail flow rules to protect against ransomware.
    - Established best practices for securing email attachments using OneDrive links, password protection, and sensitivity labels to prevent sensitive data leaks.
- #### Interactive Security Awareness Exercises:
    - Designed hands-on exercises, such as simulated phishing tests, secure document-sharing challenges, and password/MFA setup tasks, to reinforce employee cybersecurity skills.
    - Incorporated real-world scenarios to teach employees how to identify phishing emails, secure Teams messages, and configure SharePoint permissions.
- #### DLP Policies for Email and File Sharing:
    - Formulated DLP policies to monitor and control sensitive data in emails and files, using automated rules in Microsoft 365 to block unauthorized sharing.
    - Ensured compliance with regulations by restricting sensitive content (e.g., health records, financial data) from being sent externally.
- #### Protecting Data in SharePoint and OneDrive Based on Network Location:
    - Contributed to conditional access policies to restrict data access from untrusted networks, requiring MFA and device compliance checks.
    - Implemented encryption and activity logging to secure files in SharePoint and OneDrive, preventing unauthorized access from high-risk locations.
